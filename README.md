## 사용 방법

1. 위 링크를 **Chrome 또는 Edge**로 엽니다. (마이크 접근은 https 또는 localhost에서만 동작)
2. AME2를 USB-C로 PC에 연결하고 전원 버튼을 3초 이상 길게 눌러 켭니다.
3. 윈도우 소리 설정에서 입력·출력을 모두 `Maonocaster E2`로 지정합니다.
4. 사이트 1번 탭의 **장치 확인 시작**을 누르고 마이크 권한을 허용합니다.

## 핵심 요약

- **MONITOR = 내가 듣는 소리 / OUTPUT = 상대가 듣는 소리** — 가장 많이 헷갈리는 두 노브
- PC 녹음·방송에 음악을 함께 넣으려면 **LOOPBACK ON**
- 48V 팬텀 파워는 **XLR 콘덴서 마이크만**, 다이내믹은 OFF
- 게인 스위치: 콘덴서 40dB / SM7B·PodMic 50~60dB
- 충전은 **DC 5V 포트 전용** (USB-C 오디오 포트로는 충전되지 않음)
- USB 마이크·블루투스 헤드폰은 지원되지 않음

## 기술

- 외부 라이브러리 없는 순수 HTML / CSS / JavaScript
- Web Audio API (AnalyserNode, MediaRecorder, getUserMedia) 기반 실시간 분석
- 녹음은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다
- 진행률·언어·노브 세팅은 localStorage에 저장됩니다
